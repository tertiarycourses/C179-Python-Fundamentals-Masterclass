# Activity 13: Function — Future Value Calculator

**Topic 05: Function**  ·  Focus: package a business calculation as a reusable function

The FV calculation lets investors predict the profit generated by an investment. Create a function to compute the future value FV = PV × (1 + r)^n for a present value PV, annual interest rate r and n years.

**You'll build:** A reusable fv() function returning the future value of an investment.

**Tools:** Python 3 (Colab / IDE)

## Steps

1. Define the function with three parameters and return the FV formula.

   ```python
   def fv(pv, r, n):
       return pv * (1 + r) ** n
   ```

2. Call it: $10,000 invested at 5% for 10 years.

   ```python
   print(fv(10000, 0.05, 10))
   ```

3. Format the answer as money with an f-string.

   ```python
   print(f'Future value: ${fv(10000, 0.05, 10):,.2f}')
   ```

4. Try other scenarios — change the rate and the years and rerun.

   ```python
   print(f'{fv(5000, 0.03, 5):,.2f}')
   ```


## Check your result

fv(10000, 0.05, 10) prints approximately 16288.95 — formatted as $16,288.95.
