## About the course

Launch your programming journey with the Python Fundamentals Masterclass. The course gives you a solid
foundation in Python, one of the most versatile and widely-used programming languages today — syntax, data
types, operators, control structures, functions, modules and packages — through 21 hands-on activities that
build practical skills applicable across industries. It suits learners who are new to programming or who want
to switch careers into data or software roles.

## Learning outcomes

On completion of this course, learners will be able to:

- LO1: Apply Python programming to meet business requirements
- LO2: Code data types and operators
- LO3: Organize codes using conditional and loop for problem-solving
- LO4: Code Python functions and scripts for business use cases
- LO5: Code, import and prepare finance data using Python packages
- LO6: Test Python codes with aggregation and visualization
- LO7: Improve and document Python codes to analyse finance data

## Topics covered

| Topic | Coverage |
|---|---|
| 1 · Get Started on Python | Overview, install Python, IDEs (Colab / VS Code / PyCharm), first script, comments |
| 2 · Data Types | Number, String, List, Tuple, Dictionary, Set; formatting with f-strings |
| 3 · Operators | Arithmetic, compound, comparison, membership, logical |
| 4 · Control Structures, Loop & Comprehension | if/elif/else, ternary, try/except, while & for, enumerate/zip, comprehensions |
| 5 · Function | Syntax, return values, default/named/variable arguments, lambda, map, filter |
| 6 · Modules & Packages | Standard library, pip, pandas, matplotlib, yfinance — real finance data & charts |
